#### TC-PERF-001: 30 студентов одновременно

- **Приоритет:** Желательный
- **Инструмент:** k6
- **Сценарий:** 30 виртуальных пользователей выполняют логин → просмотр лаб → загрузку файла → просмотр статуса.
- **Ожидаемый результат:**
  - p95 latency < 500ms для GET.
  - p95 latency < 2s для POST с файлом.
  - 0% ошибок 5xx.
