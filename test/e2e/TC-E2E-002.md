#### TC-E2E-002: Полный цикл «сдал → доработка → исправил → принял»

- **Приоритет:** Желательный
- **Шаги:**
  1. Студент: IN_PROGRESS → SUBMITTED.
  2. Преподаватель: SUBMITTED → NEEDS_REVISION.
  3. Студент: NEEDS_REVISION → IN_PROGRESS.
  4. Студент: повторная загрузка → SUBMITTED.
  5. Преподаватель: SUBMITTED → ACCEPTED.
- **Ожидаемый результат:** Все переходы корректны, история содержит 5+ записей.
