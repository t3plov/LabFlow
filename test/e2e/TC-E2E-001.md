#### TC-E2E-001: Полный цикл «сдал → принял»

- **Приоритет:** Желательный
- **Шаги:**
  1. Студент: NOT_STARTED → IN_PROGRESS.
  2. Студент: загрузка файла → SUBMITTED.
  3. Преподаватель: SUBMITTED → ACCEPTED.
  4. Преподаватель: комментарий.
- **Ожидаемый результат:** Все шаги успешны, история статусов полная, уведомления отправлены.
